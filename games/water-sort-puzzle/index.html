HOW TO PLAY

Welcome to Water Sort Puzzle! Your goal is to sort the colored liquids so that each test tube contains only one color.


How to Play:

  • Tap on a test tube to select it
  • Tap on another test tube to transfer the liquid
  • You can only pour liquid into an empty tube or onto the same color
  • Try to solve the puzzle in as few moves as possible

Tips:

  • Plan your moves ahead
  • Use empty tubes as temporary storage
  • Try to create complete sets of colors

Good luck and have fun sorting!
